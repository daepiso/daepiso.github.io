# 대피소 찾기

내 위치에서 가까운 대피소를 자동으로 찾아 주고, 길을 안내하고,
그곳으로 지금 몇 명이 가고 있는지 알려주는 웹앱입니다.
설치도 가입도 필요 없이 링크만 열면 쓸 수 있습니다.

## 기능

1. **위치 기반 검색** — 앱을 열면 근처 대피소가 가까운 순으로 바로 뜹니다.
   민방위 대피시설, 지진 옥외대피장소, 폭염·한파 쉼터, 침수 대피소 4종을
   상단 칩으로 켜고 끌 수 있습니다.
2. **길찾기** — 버튼 하나로 카카오맵 도보 경로가 열립니다.
3. **실시간 인원** — 같은 대피소로 향하는 사람 수가 실시간으로 표시됩니다.
   익명이며, 이동 경로는 저장하지 않습니다.
4. **어르신 배려** — 큰 글씨, 큰 버튼, 높은 명암비.
   대피소 안내를 소리로 들을 수 있고, 가족에게 내 위치를 문자로 보낼 수 있습니다.

## 시작하기

키 3개(전부 무료)를 발급받아야 합니다. **[docs/setup.md](docs/setup.md)** 를 따라 하세요.

## 명령어

테스트 실행:

```bash
npm test
```

로컬에서 열기:

```bash
npm run serve
```

대피소 데이터 적재 (최초 1회, 그 뒤엔 연 1~2회):

```bash
npm run import
```
