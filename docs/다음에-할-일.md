## 2026-08-31 저녁에 한 일

### 지도가 안 나오던 문제 (컴퓨터에서만)

폰은 되는데 컴퓨터에서만 지도가 안 나왔다. 원인이 둘이었다.

**하나 — 한 번 숨기면 다시 안 나왔다.**
카카오가 준비되기 전에 그리려 하면 지도를 숨기는데, 나중에 준비돼도
다시 보여주는 곳이 없었다. `hideMap()` 만 있고 짝이 없었다.
폰은 위치를 찾는 사이 지도가 준비돼서 안 걸렸고, 컴퓨터는 저장해 둔
동네로 곧바로 그리려다 걸렸다. `showMap()` 을 만들어 짝을 맞췄다.

**둘 — 타일이 어긋났다.**
숨겨진 칸(높이 0)에 지도를 만들면 카카오가 자기 크기를 0 으로 기억한다.
나중에 보여줘도 그 크기 그대로라 전국 지도가 조각으로 붙어 보였다.
지도를 만들기 전에 먼저 칸을 보이게 하고, 그린 뒤 `relayout()` 을 부른다.
`relayout()` 은 `map.js` 에 있었지만 아무 데서도 부르지 않던 죽은 함수였다.

### 무엇을 눌러야 할지 헷갈리던 문제

스크롤하면 종류 넉 칸과 아래 띠가 나란히 놓여 누를 수 있는 네모가
여섯 개로 보였다. 넷은 **고르는 것**, 둘은 **하는 것**인데 구분이 안 됐다.

- `가족에게 알리기` 를 아래 띠에서 빼서 카드 안 `길찾기` 밑으로 옮겼다.
  코드상 원래부터 맨 위 카드의 그 대피소를 알리는 것이었다.
  화면 전체 띠에 떠 있어서 자기 자리를 못 찾고 있던 셈이다.
  아래 띠에는 `소리로 듣기` 하나만 남는다.
- 아래 띠 위쪽에 선을 넣어 다른 층임을 보였다.
- 종류 칸의 그림에서 상자를 벗겨 단추처럼 보이지 않게 했다.
  고른 것만 파란 상자가 씌워진다.
- 좁은 폰(420px 이하)에서 숨겨두던 '원하는 시설을 선택하세요' 를 되살렸다.
  스크롤하면 제목이 위로 사라져 그림 넉 개만 남는 것이 헷갈림의 뿌리였다.

**덤 — 어두운 화면에서 '대피소 종류' 제목이 안 보였다.**
밝은 화면용 남색(#243849)이 그대로 남아 대비가 1.36 이었다. 사실상 안 보인다.
제목이 안 보이면 넉 칸이 무엇을 고르는 자리인지 알 수 없다. 15.05 로 고쳤다.

겪은 함정 두 가지.

**하나 — safetydata 는 데이터마다 키가 따로 발급된다.**
하나로 다 될 줄 알았는데 SERVICE ACCESS DENIED 가 났다.
`.env` 에 SAFETYDATA_KEY_EARTHQUAKE / _HEAT_COLD / _TEMP_HOUSING
세 개를 따로 넣는다.

**둘 — 시설번호가 전국 고유가 아니다.**
지진과 임시주거의 ACMDFCLTY_SN 은 지역코드(ARCD) 안에서만 고유하다.
48번이 부산에도 전남에도 제주에도 있다. 그것만 관리번호로 쓰면
11,174건이 452건으로 줄어든다. 지역코드를 앞에 붙여 해결했고
테스트로 고정했다.

무더위쉼터는 이름 체계가 다르다(RSTR_NM, RSTR_FCLTY_NO).
필드 이름은 세 종류 모두 `--inspect` 로 실제 응답을 보고 적었다.

업로드는 15MB 를 한 번에 올리면 실패하므로
`data/upload/01.csv` ~ `06.csv` 로 나눠 올렸다.
다시 올릴 일이 있으면 `supabase/reload-shelters.sql` 로 비우고
`node scripts/build-upload-csv.mjs` 뒤 같은 방식으로 하면 된다.

민방위는 localdata.go.kr CSV 라 방식이 다르다. 8/25 기록 참고.

**침수 -> 임시주거로 대체함.** 전국 단위 '침수 대피소' 공식 데이터가
존재하지 않는다. 침수는 지자체가 각자 관리해서 전국을 모아둔 곳이 없다.
대신 이재민 임시주거시설(수해로 집을 잃었을 때 머무는 학교 체육관 등)을
쓴다. 종류 키를 `flood` -> `temp_housing`, 칩 이름을 '침수' -> '임시주거'
로 바꿨다. DB 제약도 `supabase/migrate-temp-housing.sql` 로 함께 바꿨다.

주의: data.go.kr 의 `행정안전부_이재민임시주거시설정보`
(https://www.data.go.kr/data/15124965/fileData.do) 는 **쓸 수 없다.**
받아서 열어보니 51행짜리 시도별 통계표였다. "서울특별시 1191개소" 같은
합계만 있고 시설명·주소·위경도가 없어 지도에 찍을 수 없다.
개별 위치가 있는 데이터는 safetydata.go.kr 쪽에서 신청해야 한다.

data.go.kr 파일데이터 다운로드 방법(자동화용):
1. POST /tcs/dss/selectFileDataDownload.do
   (publicDataPk, publicDataDetailPk=uddi:..., fileDetailSn, publicDataTyCode=PR0051)
   -> 응답 JSON 의 atchFileId 가 진짜 파일 ID
2. POST /cmm/cmm/fileDownload.do (atchFileId, fileDetailSn)
상세 페이지 HTML 에 처음 보이는 FILE_... 은 설명서 PDF 라 함정이다.

## 미뤄둔 것

**카카오톡 안에서 소리 내기** — 카카오톡 인앱 브라우저는 Web Speech API
를 막는다. 대신 큰 글씨로 보여주고 `크롬에서 열기` 버튼을 제공한다.

진짜 소리를 내려면 미리 만든 음성 파일(mp3/wav)을 재생해야 한다.
윈도우에 한국어 음성 엔진(Microsoft Heami)이 있어 무료로 만들 수 있음을
확인했다. 다만 대피소 이름 17,228개는 미리 녹음할 수 없어
"걸어서 N분입니다" 같은 부분만 소리로 낼 수 있다.
WAV 크기는 8kHz 기준 문장당 약 80KB. 압축 도구(ffmpeg 등)는 없다.

필요해지면 이 조사 결과부터 다시 보면 된다.
