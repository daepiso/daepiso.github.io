## 바로 이어서 할 것

### 1. 폰에서 아직 못 눌러본 것

- `길찾기` → 카카오맵이 열리는지
- `가족에게` → 문자 앱이 열리고 본문이 채워지는지

### 2. 대피소 종류 추가 (지금은 민방위만 있음)

**지진 옥외대피장소** — 가장 쉽다. 10분이면 된다.

1. https://www.data.go.kr/data/15072620/standard.do 접속
2. 우측 목차 "파일데이터 정보" 클릭
3. `URL` 항목의 https 주소를 복사해서 알려주기

민방위 때와 똑같은 방식이다. 파일은 자동으로 받아서
`scripts/build-upload-csv.mjs` 로 변환한 뒤 Supabase 에 올리면 된다.
`scripts/normalize.js` 의 `FIELD_MAP` 에 `earthquake` 항목만 추가하면 된다.

**무더위쉼터** — safetydata.go.kr 에서 신청했다. 승인대기.

**침수 -> 임시주거로 대체함.** 전국 단위 '침수 대피소' 공식 데이터가
존재하지 않는다. 침수는 지자체가 각자 관리해서 전국을 모아둔 곳이 없다.
대신 이재민 임시주거시설(수해로 집을 잃었을 때 머무는 학교 체육관 등)을
쓴다. 종류 키를 `flood` -> `temp_housing`, 칩 이름을 '침수' -> '임시주거'
로 바꿨다. DB 제약도 `supabase/migrate-temp-housing.sql` 로 함께 바꿨다.

## 미뤄둔 것

**카카오톡 안에서 소리 내기** — 카카오톡 인앱 브라우저는 Web Speech API
를 막는다. 대신 큰 글씨로 보여주고 `크롬에서 열기` 버튼을 제공한다.

진짜 소리를 내려면 미리 만든 음성 파일(mp3/wav)을 재생해야 한다.
윈도우에 한국어 음성 엔진(Microsoft Heami)이 있어 무료로 만들 수 있음을
확인했다. 다만 대피소 이름 17,228개는 미리 녹음할 수 없어
"걸어서 N분입니다" 같은 부분만 소리로 낼 수 있다.
WAV 크기는 8kHz 기준 문장당 약 80KB. 압축 도구(ffmpeg 등)는 없다.

필요해지면 이 조사 결과부터 다시 보면 된다.
