```

```

## 3. 실시간 인원

| 단계 | 인원 |
| --- | --- |
| 시작 전 | 0 |
| 길찾기 누른 뒤 | 1 |
| 실시간 알림 수신값 | 1 (새로고침 없이 전파) |
| 도착 처리 뒤 | 0 |

기기 ID는 익명 UUID로 발급된다.

미확인: 2분 무응답 시 자동 만료(`expire_stale_trips`)는 실기기에서 시간을 두고 확인해야 한다.
