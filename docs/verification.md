### 발견한 결함과 수정

**결함 1 — 안내창이 화면 전체를 막음**

`.consent` 에 `display: grid` 를 지정한 탓에 `hidden` 속성의
`display: none` 이 무시됐다. 시작하기를 눌러도 투명한 막이 남아
아래 버튼이 전혀 눌리지 않았다.

수정: `[hidden] { display: none !important; }`

**결함 2 — 인앱 브라우저에서 소리 버튼이 사라짐**

`isSpeechSupported()` 가 false 면 버튼을 숨기도록 만들었는데,
카카오톡 인앱 브라우저가 여기 해당했다. 어르신 입장에서
버튼이 없어지면 원인을 알 수 없다.

수정: 버튼을 항상 보이게 하고, 소리가 안 나면 같은 문장을
22px 굵은 글씨로 화면에 표시한다. 안드로이드에서 늦게 채워지는
목소리 목록도 기다리도록 했다.

**결함 3 — 고쳐도 폰에 반영되지 않음**

GitHub Pages 의 `Cache-Control: max-age=600` 때문에 새로고침해도
최대 10분간 예전 파일이 쓰였다. 재난 앱에서는 위험하다.

수정: 배포마다 `style.css`, `main.js` 주소에 커밋 해시를 붙인다.
아울러 GitHub Actions 로 `dist/` 만 배포하도록 바꿔, 문서와 원본
CSV 가 인터넷에 노출되지 않게 했다.
