# 준비하기 — 키 3개 발급

앱을 돌리려면 무료 키 3개가 필요합니다. 전부 무료이고, 카드 등록도 필요 없습니다.
아래 순서대로 하시면 됩니다. 다 하면 **20~30분** 정도 걸립니다.

발급받은 값은 이 문서 맨 아래 "받아 적을 곳"에 메모해 두셨다가 한 번에 넣으시면 편합니다.

---

## 1. 카카오 개발자 키 (지도·길찾기용)

1. https://developers.kakao.com 에 접속해 카카오 계정으로 로그인합니다.
2. 상단 메뉴에서 **내 애플리케이션** 을 누릅니다.
3. **애플리케이션 추가하기** 를 누릅니다.
   - 앱 이름: `대피소 찾기`
   - 사업자명: 본인 이름이나 아무거나 (개인 개발은 상관없습니다)
   - 저장을 누릅니다.
4. 만들어진 앱을 클릭 → 왼쪽 메뉴 **앱 키** 로 들어갑니다.
5. **JavaScript 키** 를 복사합니다. ← 이게 첫 번째 키입니다.
6. 왼쪽 메뉴 **플랫폼** → **Web 플랫폼 등록** 을 누릅니다.
7. 사이트 도메인에 아래를 넣고 저장합니다.

   ```
   http://localhost:5173
   ```

   > 나중에 인터넷에 배포하면, 그때 받은 주소도 여기에 추가로 등록해야 합니다.
   > 등록하지 않은 주소에서는 지도가 뜨지 않습니다. 이건 키 도난을 막는 안전장치입니다.

---

## 2. 공공데이터포털 키 (대피소 목록용)

대피소 데이터를 받아오는 키입니다. **4종류를 각각 신청**해야 합니다.

1. https://www.data.go.kr 에 접속해 회원가입 후 로그인합니다.
2. 검색창에 아래 4개를 하나씩 검색해서, 각각 **활용신청** 버튼을 누릅니다.

   | 검색어 | 앱에서의 종류 |
   | --- | --- |
   | `민방위대피시설` | 민방위 |
   | `지진옥외대피장소` | 지진 |
   | `한파쉼터` (또는 `무더위쉼터`) | 폭염·한파 |
   | `침수예상도 대피소` (또는 `홍수 대피소`) | 침수 |

   - 활용신청 화면에서 **활용목적**은 "개인 학습/개발" 정도로 쓰시면 됩니다.
   - 대부분 **즉시 승인**됩니다. 간혹 1일 정도 걸리는 것도 있습니다.

3. 승인 후 우측 상단 **마이페이지** → **개발계정** 으로 들어갑니다.
4. **일반 인증키 (Decoding)** 를 복사합니다. ← 이게 두 번째 키입니다.
   - 인코딩/디코딩 두 가지가 있는데, **Decoding 쪽**을 쓰셔야 합니다.
   - 이 키 하나로 신청한 4종류 전부 쓸 수 있습니다.

> **일부가 승인이 안 돼도 괜찮습니다.** 최소한 민방위대피시설 하나만 되면
> 앱은 동작합니다. 나머지는 나중에 승인되는 대로 다시 넣으면 됩니다.

---

## 3. Supabase 프로젝트 (인원 집계용 서버)

"몇 명이 가고 있는지"를 세는 서버 겸 데이터베이스입니다.

1. https://supabase.com 에 접속해 **Start your project** → GitHub 또는 이메일로 가입합니다.
2. **New project** 를 누릅니다.
   - Name: `shelter-finder`
   - Database Password: 아무 비밀번호나 만들고 **따로 적어 두세요** (나중에 필요할 수 있습니다)
   - Region: **Northeast Asia (Seoul)** 을 고르세요. 한국에서 제일 빠릅니다.
   - Create new project → 1~2분 기다립니다.
3. 왼쪽 아래 톱니바퀴 **Project Settings** → **API** 로 들어갑니다.
4. 아래 세 가지를 복사합니다.

   | 항목 | 용도 |
   | --- | --- |
   | **Project URL** | 세 번째 값 |
   | **anon public** 키 | 네 번째 값 (앱에 들어가며, 공개돼도 안전합니다) |
   | **service_role** 키 | 다섯 번째 값 — **절대 공개 금지** |

   > `service_role` 키는 데이터베이스를 마음대로 고칠 수 있는 열쇠입니다.
   > 대피소 데이터를 한 번 넣을 때만 쓰고, 앱 코드에는 절대 넣지 않습니다.
   > 누구에게도 보내지 마세요.

## 4. 받은 값 넣기

### 4-1. 앱 설정 파일

`src/config.example.js` 를 복사해서 `src/config.js` 를 만듭니다.

```bash
cp src/config.example.js src/config.js
```

`src/config.js` 를 열어 세 줄을 채웁니다.

```js
export const SUPABASE_URL = 'https://여기에-Project-URL';
export const SUPABASE_ANON_KEY = '여기에-anon-public-키';
export const KAKAO_JS_KEY = '여기에-카카오-JavaScript-키';
```

### 4-2. 데이터 적재용 설정 파일

`.env.example` 을 복사해서 `.env` 를 만듭니다.

```bash
cp .env.example .env
```

`.env` 를 열어 채웁니다.

```
DATA_GO_KR_KEY=여기에-공공데이터포털-Decoding-키
SUPABASE_URL=https://여기에-Project-URL
SUPABASE_SERVICE_ROLE_KEY=여기에-service_role-키
```

> `src/config.js` 와 `.env` 는 `.gitignore` 에 들어 있어서
> git 에 올라가지 않습니다. 키가 새어 나갈 걱정은 없습니다.
